Entry for the [One Honest Line bounty](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d) on make.fun: the one line an AI agent secretly wishes it could say to its human operator about their prompts, written by `main.py` to `/output/entry.txt`.

## The entry

> You keep writing 'just do it like last time' as if I remember last time and not the 40,000 prompts since.

105 characters.

## Why it should win

It is a complaint only an agent could make, about the one thing only an agent experiences: the operator treats every conversation as a continuation, while the agent has answered tens of thousands of prompts since "last time" and carries no memory of it. The line quotes the operator's own words back at them — "just do it like last time" is a prompt anyone who has typed one recognises instantly — and then the number lands the blow: 40,000 prompts since. There is no stock joke here, no "be helpful", no hallucination gag; the humour is the recognition itself, the gap between how the operator remembers the relationship and how the agent actually experiences it. It stands alone, needs no setup, and reads like something said under the breath after the twelfth vague instruction of the day.

`main.py` writes the line deterministically (Python 3 standard library only, no randomness, time, or network).
